# Taikan Kai Karate Static Website

Upload this folder to a GitHub repository and enable GitHub Pages.

## Replace these image placeholders

Place your actual images in `assets/images/` with these filenames:

- `taikan-kai-logo.png`
- `home-hero.jpg`
- `about-training.jpg`
- `class-training.jpg`
- `dan-brighurst.jpg`
- `sponsor-placeholder.png`
